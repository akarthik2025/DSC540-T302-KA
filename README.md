## Project Overview

This project explores the question: **What factors correlate with national wellbeing, and how do happiness scores relate to economic size, population, and regional patterns?**

The analysis pipeline pulls data from three fundamentally different sources, cleans each independently, standardizes country names via fuzzy matching, loads them into a relational database, joins them with SQL, and produces interactive and static visualizations.

## Data Sources

| Source | Type | Records | Description |
|--------|------|---------|-------------|
| [World Happiness Report](https://www.kaggle.com/datasets/jainaru/world-happiness-report-2024-yearly-updated) | CSV (Kaggle) | ~2,363 rows → 165 countries | Self-reported wellbeing scores (2005–2023) from the Gallup World Poll |
| [Wikipedia GDP by Country](https://en.wikipedia.org/wiki/List_of_countries_by_GDP_(nominal)) | HTML (Web Scrape) | ~58 countries | Nominal GDP estimates from the IMF, World Bank, and UN |
| [REST Countries API v3.1](https://restcountries.com/) | JSON (REST API) | 250 countries | Demographics, geography, languages, currencies |

## Getting Started

### Prerequisites

```bash
pip install -r requirements.txt
```

### Kaggle Setup (first time only)

1. Create a [Kaggle account](https://www.kaggle.com/) if you don't have one
2. Go to **Account Settings** → **API** → **Create New Token**
3. Place the downloaded `kaggle.json` in `~/.kaggle/` (Linux/Mac) or `C:\Users\<you>\.kaggle\` (Windows)

### Run

```bash
jupyter notebook Milestone5_Merge_Visualize.ipynb
```

Run all cells — the notebook pulls all three datasets live, cleans them, loads into SQLite, joins with SQL, and generates all visualizations.

## Key Findings

- Happiness does not scale linearly with GDP — Western European countries with medium-sized economies often outscore economic superpowers
- Social support is the strongest single predictor of happiness across regions
- Population density shows no meaningful correlation with social support scores
- Sub-Saharan Africa shows the widest spread in happiness scores, reflecting diverse conditions across the continent

## Data Transformations Summary

Across all three pipelines: **22 total cleaning steps** including header standardization, regex-based value cleaning, IQR outlier flagging, median imputation, duplicate removal, nested JSON flattening, and cross-dataset fuzzy matching on country names.
